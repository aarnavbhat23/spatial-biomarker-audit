# Reproduce the spatial raw-image development subset

This source-only package retrieves field 000 from
[Tsui et al., MERFISH 4T1 Tissue Raw Unaligned Images](https://doi.org/10.5281/zenodo.15678603),
CC BY 4.0. Complete creator metadata are fetched and retained. It selects nine
ZIP members by their fixed field identifier, validates their CRC32 and records
SHA-256. It does not download the complete 171 GB parent archive.

Allow about **5 GB free disk** and a **3.2 GB download**. There are no paid services.
Run from the repository root after installing `requirements.txt` and
`requirements-geometry.txt`:

```sh
python datasets/spatial_v01/acquire_metadata.py
python datasets/spatial_v01/acquire_spatial.py
python datasets/spatial_v01/build_spatial.py
python datasets/spatial_v01/finish_inventory.py
python study_measured_barcodes.py --dataset-root datasets/spatial_v01
python verify_measured_barcodes.py --dataset-root datasets/spatial_v01
```

Generated raw images, metadata copies and arrays are ignored by Git. Acquisition
is resumable; exact-range responses, expanded sizes and CRC32 must match before
a TIFF is accepted. `reference_checksums.json` records the original run's four
analysis inputs. `finish_inventory.py` verifies the immutable source-derived
pixels/codebook and records rebuilt metadata/transform hashes. Minor numerical
registration differences can occur across library/platform versions; inspect
them rather than changing stored research results without explanation.

The [dataset card](spatial/DATASET_CARD.md) describes the original development
release. This reduced reproducer creates the source/image audit and analysis
inputs; repository tests and the separate measured-barcode replay validate the
research computation. Historical metadata-only audits and the original full
release validation report are not generated by this reduced package.

Only one development field is included. Candidate assignments are not molecular
truth, image tiles are not independent specimens, and fiducial consistency is
not a calibrated localization-error bound. See the frozen
[research protocol](../../MEASURED_SPATIAL_PROTOCOL.md) before using outputs.
